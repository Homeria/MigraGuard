# 🖥️ 네이티브: 07. 전역 및 공통 플래그 (Global Flags)

이 플래그들은 루트 레벨에서 관리되며 모든 서브 명령어의 동작에 영향을 미칩니다.

---

## 1. 설정 관련 플래그

| 플래그 | 설명 | 기본값 |
| :--- | :--- | :--- |
| `--config` | `migraguard.yaml` 설정 파일의 경로를 지정합니다. 이 파일은 복잡한 DSN, 수집 주기, 리스크 임계값 등의 기본값을 담고 있습니다. | `./migraguard.yaml` |

---

## 2. 디버깅 및 로깅

| 플래그 | 약어 | 설명 |
| :--- | :--- | :--- |
| `--verbose` | `-v` | **상세 모드**. 고정밀 로그를 활성화합니다. 연결 문제 해결이나 SQL 파서의 로우 데이터를 확인하고 싶을 때 사용하십시오. |

---

## 3. 설정 우선순위
MigraGuard는 다음과 같은 엄격한 설정 계층을 따릅니다:
1.  **CLI 플래그** (가장 높음)
2.  **환경 변수** (`MIGRAGUARD_...`)
3.  **설정 파일** (`migraguard.yaml`)
4.  **내부 기본값** (가장 낮음)
