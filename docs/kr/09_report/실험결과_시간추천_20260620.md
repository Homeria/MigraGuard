# 시간 추천 Forecast 테스트 결과 - 2026-06-20

## Forecast 시나리오

시간 추천 테스트에는 `21_time_recommendation_orders.yaml` 시나리오를 사용하였다. 해당 시나리오는 `orders` 테이블을 대상으로 새벽 시간대에는 낮은 요청량을, 주간과 저녁 시간대에는 높은 요청량을 갖도록 구성하였다.

MigraGuard는 각 시간대의 예상 TPS, 예상 P99 응답 지연, DDL 잠금 수준, 예상 차단 시간 및 영향 요청 수를 함께 사용하여 실행 후보 시간을 판정한다. Safe 후보가 있으면 가장 낮은 위험도의 Safe 시간을 추천하고, Safe 후보가 없지만 Warning 후보가 있으면 가장 낮은 위험도의 Warning 시간을 조건부 추천한다. 모든 시간대가 Danger이면 추천 가능한 실행 시간이 없다고 판단한다.

## 핵심 해석

DDL-3은 낮은 부하 시간대에서도 P99 응답 지연을 크게 증가시켰다. 따라서 시간 추천은 단순히 TPS가 가장 낮은 시간을 고르는 방식으로는 충분하지 않다. MigraGuard는 DDL 잠금 특성, 예상 차단 시간, 예상 영향 요청 수를 함께 고려하여 DDL-3에는 02시를 Warning 조건부 후보로 제시하고, DDL-2에는 02시를 Safe 실행 후보로 제시하였다.
