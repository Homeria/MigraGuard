# 🖥️ Native: 04. Export Sandbox

The Export Sandbox command extracts all metrics stored in an offline simulation file to a structured CSV.

---

## 1. Execution Examples

**Bash**
```bash
./migraguard export-sandbox -i scenario.db -o output.csv
```

**PowerShell**
```powershell
.\migraguard.exe export-sandbox -i scenario.db -o output.csv
```

**CMD**
```cmd
migraguard.exe export-sandbox -i scenario.db -o output.csv
```

---

## 2. Detailed Flag Reference

| Flag | Shorthand | Default | Description |
| :--- | :--- | :--- | :--- |
| `--input` | `-i` | **(Required)** | **Source Database**. Path to the SQLite sandbox file generated by the `simulate` command. |
| `--output` | `-o` | **(Required)** | **Target CSV Path**. The file path where the extracted metrics will be saved. |

---

## 3. Data Fields in CSV
The exported CSV contains: `Timestamp`, `TableName`, `TableSize`, `ReplicationLag`, `ActiveConnections`, `P99Time`, `TPS`, `SharedBlksHit`, and `SharedBlksRead`.
