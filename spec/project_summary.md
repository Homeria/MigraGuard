# MigraGuard 프로젝트 개요 및 분석

## 1. 프로젝트 정의 (What is MigraGuard?)
**MigraGuard**는 데이터베이스 스키마 변경(DDL) 시 발생할 수 있는 락(Lock) 경합 및 서비스 장애를 사전에 차단하는 **DevSecOps CLI 도구**입니다. 운영 DB의 실제 쿼리 워크로드(`pg_stat_statements`)를 시계열로 수집하고, 마이그레이션 스크립트를 분석하여 배포 안전성을 정량적으로 평가합니다.

## 2. 핵심 가치 (Core Value)
> "트래픽을 모르는 DDL은 시한폭탄과 같다."
- **동적 워크로드 인지:** 정적 분석에 그치지 않고 실제 운영 트래픽 패턴을 고려함.
- **최적 배포 시간대(Safe Window) 추천:** 통계적 데이터(중앙값 등)를 기반으로 장애 위험이 최소화되는 시간대를 제시함.
- **자동화된 게이트키퍼:** CI/CD 파이프라인과 통합되어 위험한 배포를 원천 차단.

## 3. 주요 기능 명세 (Full Spec 기반)
1. **백그라운드 워크로드 수집:** 운영 DB에서 주기적으로 쿼리 실행 통계를 수집하여 로컬 SQLite에 시계열 데이터로 저장.
2. **SQL AST 파싱:** `pganalyze/pg_query_go`를 통해 DDL이 영향을 미치는 테이블, 컬럼 및 요구되는 락 레벨 식별.
3. **교차 검증 및 위험도 산출:**
   - 파싱된 대상 테이블의 실시간/과거 트래픽 밀도 확인.
   - `EXPLAIN` 및 `pg_stat_activity`를 연동한 다각도 검증.
4. **시각화 및 리포팅:** CLI 터미널 출력 및 GitHub PR에 분석 결과 자동 코멘트(차트 및 마크다운).
5. **서킷 브레이커(Circuit Breaker):** 임계치 초과 시 배포 프로세스 강제 중단(`Exit 1`).

## 4. 기술 스택
- **언어:** Go (Golang) - 단일 바이너리 배포 및 고루틴을 통한 효율적 데이터 수집.
- **데이터베이스:** SQLite (내장형 시계열 저장소), PostgreSQL (대상 운영 DB).
- **주요 라이브러리:** `pg_query_go` (AST 파서), `cobra` (CLI), `pgx` (DB Driver).
