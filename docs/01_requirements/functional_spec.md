# 🛡️ MigraGuard 프로젝트 기능 명세서 (Functional Specification)

## 1. 프로젝트 정의
**MigraGuard**는 PostgreSQL의 스키마 변경(DDL) 시 발생할 수 있는 서비스 장애 리스크를 사전에 탐지하는 **트래픽 인지형(Traffic-Aware) 데이터베이스 가드레일**입니다. 운영 환경의 실시간 트래픽 패턴과 SQL의 정적 특성을 교차 분석하여 배포 안전성을 정밀하게 검증합니다.

## 2. 핵심 가치 및 목표
- **정밀한 부하 추적**: 누적 지표의 변화량(Delta) 측정을 통한 정확한 시점별 TPS 산출.
- **실환경 모사 검증**: 24시간 트래픽 곡선과 비즈니스 시나리오를 반영한 고충실도 시뮬레이션 환경 제공.
- **보수적 리스크 모델**: 실시간 부하 강도에 따라 유동적으로 변화하는 5단계 위험도 평가 엔진 구축.
- **자동화된 게이트키핑**: 위험 등급(Danger) 감지 시 배포 파이프라인(CI/CD)을 즉시 차단하여 장애 예방.

## 3. 주요 기능 세부 사항 (v3.5)

### 3.1. 고충실도 부하 생성기 (Load Generator)
- **도메인 기반 부하**: 이커머스 도메인(주문, 재고, 상품)의 복잡한 트랜잭션 상황을 재현.
- **트래픽 곡선 적용**: 사인파(Sine Wave) 공식을 이용해 시간대별 트래픽 변동을 현실적으로 모사.
- **동시성 제어**: 워커 풀(Worker Pool) 구조를 통해 대규모 동시 접속 상황에서의 락 경합 재현.

### 3.2. 지능형 수집 에이전트 (Background Agent)
- **지표 누적 및 정제**: `pg_stat_statements`를 활용하여 테이블별 읽기/쓰기 성능 지표 수집.
- **데이터 연속성 보장**: 에이전트 재시작 시에도 누적 지표의 손실 없이 델타 값을 계산하는 로직 탑재.
- **자동 저장소 관리**: SQLite 저장소의 용량 최적화를 위한 주기적인 가비지 컬렉션(Retention) 수행.

### 3.3. 동적 리스크 평가 엔진 (Risk Engine)
- **가중치 기반 TPS**: `Max(실시간, 1시간 평균, 24시간 피크)` 기준의 보수적 리스크 등급 산출.
- **5단계 정밀 리포트**: 큐잉 이론 기반의 상세 지표($T_{ddl}, T_{block}, C_{peak}, T_{rec}$)를 정량적으로 제공.
- **부하 원인 분석**: 현재 DB 리소스를 점유 중인 상위 3개 쿼리(Top Heavy Queries) 정보 및 영향도 출력.
- **SQL 원문 연동**: 분석된 DDL 문장의 실제 원문을 리포트에 포함하여 식별성 강화.
- **배포 골든타임 추천**: 최근 24시간 데이터를 분석하여 리스크가 가장 낮은 안전 배포 시간대 제시.

### 3.4. 운영 가시성 및 인프라
- **실시간 요약 로그**: 에이전트(수집량) 및 부하 생성기(트랜잭션 수)의 작업 현황을 주기적으로 출력.
- **멀티 바이너리 컨테이너**: 단일 도커 이미지 내에서 분석 도구와 시뮬레이터를 독립적으로 실행 가능.
