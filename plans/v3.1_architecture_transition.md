# MigraGuard v3.1 아키텍처 전환 계획 (Agent-CLI 분리)

## 1. 개요
현재 `analyze` 명령 실행 시점에만 일시적으로(3초간) 데이터를 수집하던 방식(v3.0)에서, 상시 수집 에이전트(Agent)와 즉각 분석 도구(CLI)가 분리된 **v3.1 에이전트 모델**로 전환합니다.

## 2. 주요 변경 사항

### 2.1. 커맨드 구조 이원화
- **`migraguard agent` (Background):** 운영 DB 옆에서 상시 가동하며 지표를 수집하여 SQLite에 저장.
- **`migraguard analyze` (Foreground):** 이미 수집된 SQLite 데이터를 즉시 쿼리하여 리스크를 분석 (대기 시간 제거).

### 2.2. 리스크 엔진 고도화
- 3초간의 짧은 델타 지표 대신, SQLite에 축적된 **최근 1시간 평균 TPS, 24시간 피크 TPS** 등을 활용하여 분석 정밀도 향상.

### 2.3. 데이터 관리 및 인프라
- Docker Volume을 활용한 SQLite 파일 공유 메커니즘 정의.
- 오래된 데이터를 삭제하는 데이터 보존 정책(Retention Policy) 도입.
