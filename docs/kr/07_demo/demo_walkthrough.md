# MigraGuard 시연 문서 안내

최신 캡스톤디자인 발표 시연과 보고서 실험 재현 명령은 다음 문서를 기준으로 한다.

- [발표 시연 가이드](./demo_presentation_guide.md)

해당 문서에는 다음 내용이 포함되어 있다.

1. 대표 DDL 021을 이용한 약 5분 분량의 Squawk 및 MigraGuard 비교 시연
2. DDL 022~036의 Squawk 통과 결과 검증
3. DDL 037~041의 Squawk 경고 결과 검증
4. Default 설정의 400개 조합 비교 실험과 히트맵 생성
5. Low, Default, High Capacity 설정의 1,200개 조합 비교 실험과 히트맵 생성
6. 발표 질문 대응 및 원격 접속 장애 대비 체크리스트

기존 001~020 DDL과 forecast 중심의 시연 명령은 현재 최종보고서의 비교 실험과 다르므로 최신 발표에서는 사용하지 않는다.
