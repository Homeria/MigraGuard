# Native: 02. Analyze (Risk Assessment)

The `analyze` command parses a migration SQL file and evaluates DDL risk using either live PostgreSQL metrics or a SQLite simulation sandbox.

---

## 1. Live Mode

Live mode connects to PostgreSQL for current table metrics and uses a local SQLite metrics store for historical workload baselines.

**Bash**
```bash
./migraguard analyze migration.sql --db "postgres://user:pass@host:5432/db" --sqlite migraguard.db
```

**PowerShell**
```powershell
.\migraguard.exe analyze migration.sql --db "postgres://user:pass@host:5432/db" --sqlite .\migraguard.db
```

If `--db` or `--sqlite` is omitted, MigraGuard falls back to `--config` values and then built-in defaults.

---

## 2. Sandbox / Offline Mode

Sandbox mode does not connect to live PostgreSQL. It reads a SQLite sandbox generated by `simulate` and uses it through a virtual PostgreSQL adapter.

**Bash**
```bash
./migraguard analyze migration.sql --sandbox exp_05_spike_flash_sale.db
```

**PowerShell**
```powershell
.\migraguard.exe analyze migration.sql --sandbox .\exp_05_spike_flash_sale.db
```

When `--sandbox` is set, `--db` is ignored.

---

## 3. Report Output

**Markdown**
```bash
./migraguard analyze migration.sql --sandbox exp_05_spike_flash_sale.db --output markdown > report.md
```

**CSV**
```bash
./migraguard analyze migration.sql --sandbox exp_05_spike_flash_sale.db --output csv > result.csv
```

When appending multiple CSV runs, use `--no-header` after the first run.

```bash
./migraguard analyze migration.sql --sandbox exp_05_spike_flash_sale.db --output csv --no-header >> result.csv
```

---

## 4. 24-Hour Forecast

Use `--forecast` to calculate risk across a 24-hour workload profile stored in SQLite.

```bash
./migraguard analyze migration.sql --sandbox exp_05_spike_flash_sale.db --forecast
```

Notes:
- `--forecast` currently has no shorthand. `-f` is not supported.
- When forecast data is generated, MigraGuard writes `predictive_forecast.csv` in the current working directory.
- The current CLI does not provide a flag to customize the forecast CSV path.

---

## 5. Detailed Flag Reference

| Flag | Shorthand | Default | Description |
| :--- | :--- | :--- | :--- |
| `--db` | - | config value | PostgreSQL DSN for Live mode. |
| `--sqlite` | - | `migraguard.db` or config value | Local SQLite workload store written by the Agent. |
| `--sandbox` | `-s` | - | SQLite simulation sandbox path. Enables Offline mode and skips live PostgreSQL. |
| `--output` | `-o` | `console` | Output format. Intended values are `console`, `markdown`, and `csv`. |
| `--no-header` | - | `false` | Suppress the CSV header when using `--output csv`. |
| `--forecast` | - | `false` | Enable 24-hour predictive risk analysis. |

Note: the current implementation falls back to `console` output for unrecognized `--output` values instead of returning an error. Use only `console`, `markdown`, or `csv`.

---

## 6. Exit Codes

| Exit code | Meaning |
| :--- | :--- |
| `0` | The result is `Safe` or `Warning`. |
| `1` | The result is `Danger`, or initialization/parsing/analysis failed. |

For CI/CD usage, remember that both a deliberate `Danger` gate and an internal error are represented as exit code `1`.
